About this mock-up (not part of the design)

  • The total is a net. Holidays + Off days − added = how many shoot days the wrap moved. It can be 0 ("no shoot days lost") or below 0 ("2 shoot days gained"). Try the last two shoots.
  • "Added" now means a weekend worked. A holiday you work isn't lost, so it isn't added either. Counting it as both would knock the total off by one. In "Off and worked days" Independence Day is worked, so it's in neither count; hover the holidays to see it named.
  • Weeks is the meta line's "→ 17 wk". In C to F it moves onto the dashed line, since it isn't part of the sum.
  • Smaller window shows the card at a 1440 px window. The sidebar grows with the window, so a smaller screen means a narrower card. A wrapped row here can start with a stray divider; the built line already hides that, so ignore it.
  • The shoots are made up. Only the date, the span and what's under it are drawn.
