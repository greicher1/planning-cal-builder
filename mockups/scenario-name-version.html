Name a scenario after its Version

While a tab's name is being typed, one suggestion sits above the box: Use Version. Take it and the tab's name is linked to that tab's Version (the small link mark), so it changes whenever the Version does. Type your own name and the link is gone. Nothing is renamed unless you pick it.
