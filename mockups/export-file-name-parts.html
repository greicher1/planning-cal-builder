How it behaves

  • Every part starts on, so the name is today's until you change it.
  • The show title always stays, so a file never ends up named just "Planning Calendar 2026-11-18.pdf".
  • A part with nothing to say isn't offered: no season, no Writers' Room date, no Version or one scenario, and that part doesn't appear.
  • Put all back shows once something is off.
  • The order stays fixed: title, season, WRO, words, date, Version, scenario.

Your calls, once you pick a layout

  • Who remembers the picks? Saved with the calendar (everyone who opens it gets the same names), or kept on this computer (your own habit).
  • Which exports follow? Just this PDF, or the Excel file and the month PDF too. Excel has no window of its own today, so it would follow what you picked here.
  • Type a part? For example change "Planning Calendar" to "Waterfall". Not in this mockup.
