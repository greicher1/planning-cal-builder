Beside the tabs was measured and dropped: the line keeps its width, so the tabs are squeezed into whatever is left (1 tab in view at 1440 px).

What the line shows

  • Location: what you typed in Show info's new Location box. If it's blank, the Production Region, shortened (table at the bottom).
  • Episodes: "5 blocks" instead when a calendar is scheduled by blocks.
  • Writers' Rm: the date it opens, then its length in weeks. This drops out when a calendar has no writers' room.
  • Production: the first shoot day, then the production span in weeks.
  • Wrap: the last shoot day.
  • Grey marks a value that's the same in every scenario, as the Compare window greys a row that's the same everywhere. What's left dark is what differs, and as you flip, only the dark values change.
  • It's the same in the month view. It has no setting, and the line itself is never saved, printed or exported.

Location, in Show info

The Production Region stays what it is today: it picks the union holidays. Under it, a new optional Location box takes any text. When it's filled in, that text is what the line and the Compare window show. Try it: pick a scenario with any tabs above, then type in the box.

Compare window (top rows)
  • Each scenario keeps its own Location, like every other Show info field, so "Toronto" and "Winnipeg" can sit side by side.
  • Saved with the calendar. A calendar saved before this has no Location, so it shows its region, exactly as it does now.
  • It never changes a date. Only the Production Region decides holidays. Typing "Winnipeg" with the region left on Toronto keeps Toronto's holidays.
