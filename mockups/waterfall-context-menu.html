How it behaves

  • It is the month view’s day menu, shaped for a grid of weeks: the same look, the same keys, and the same fixed order. The clipboard row and “This week” come first, so they never move. Below them is one section for the cell you clicked: a phase week, a note, a hiatus band, a holiday.
  • Right-click inside a highlight acts on all of it, as Excel does. Right-click outside it highlights that one cell first.
  • A choice the app refuses is greyed out with its reason, never hidden.
  • Cut, Copy, Paste and Clear are the same actions as ⌘X ⌘C ⌘V Delete, which are being built now in their own session. The menu only calls them.
  • Shift + right-click still opens the browser’s own menu.
  • In the open menu: ↑ ↓ move, ← → move along the clipboard row or open a submenu, Enter chooses, Esc closes.
  • Each item is one undo step. Nothing in it changes how a cell looks, so it needs no frozen edit.

Ruled (owner, 22 Oct 2026)

1. The clipboard row stays at the top.As Excel’s Paste Options row, rather than plain lines inside the Note section.

2. Clear can remove an automatic note.It is kept as “cleared”, so it stays empty when dates move, and Reset Notes brings it back. The first Delete note in either menu (the month menu has none, ruling Q5).

3. The Size section stays.Reset row height / column width, which today only a double-click on the edge does.

4. Show this day or week in the month view.On a dated note (or a holiday shown in a Notes cell) it reads “Show this day” and lands on that day, highlighted for a moment. Everywhere else it is “Show this week”, and the week is highlighted. Try it on “The wrap note”, dated Tuesday 9/1.

Left out on purpose

  • Shift From, Anchor To, Rebuild From. Kept out of the month menu by your ruling M1, so kept out here too.
  • Text styling. The Text bar above the calendar already styles any highlight.
  • Add 1-day phase here. A waterfall row is a week, so a one-day phase looks the same as a one-week one. The month menu has it.
  • Insert or delete a row or column. Rows are weeks and columns are phases; both come from the dates.
  • The title block. It has its own editor: double-click a line.
